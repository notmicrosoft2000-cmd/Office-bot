What the bot does

  • Join gate — new members must submit an Among Us friend code or declare they don't play within a set time, or they're removed.
  • Index — a moderator-approved list of friend codes and Discord IDs tied to reported misconduct.
  • Ban evasion detection — friend codes are permanent and account-bound, so they catch people changing Discord accounts.
  • Reports — members can report misconduct; reports only enter the index after a moderator approves them.

Note: AU Gate is a community-run bot. It is not affiliated with, endorsed by, or operated by Discord Inc. or Innersloth LLC.
